# D1.4 — Fast pruning SEE

Status: **COMPLETE — CORRECTNESS PASS, PERFORMANCE REJECTED**

Candidate profile:

```text
current-qsearch-fast-pruning
```

This is bench-only. It is not exposed through UCI and does not change
`Current`.

## Scope

D1.4 replaces only the pruning-specific SEE attacker discovery used by
`current-qsearch-pruning`:

```text
see_ge_for_pruning(position, move, threshold = 0) -> Option<bool>
```

The replacement uses direct target-relative occupancy walks for pawns,
knights, kings, bishops, rooks, and queens. It keeps the existing legal
attacker validation and the D1.3 exchange back-propagation. It does not change
the qsearch move list, SEE threshold, move order, evaluation, TT, or any main
search pruning feature.

The result contract is:

```text
Some(true)  => supported SEE >= 0; keep
Some(false) => supported SEE < 0; prune
None        => unsupported exchange; fail open
```

Promotion and en-passant protections remain unchanged. In particular, any
initial or later promotion returns `None`, and the caller keeps the move.

## Correctness gate

The D1.4 test compares D1.3 and D1.4 directly on ordinary captures, defended
captures, x-rays, en passant, promotions, the white/black promotion-fail-open
positions, and a deterministic 256-ply legal walk. For every compared
position, the kept move set, `qsearch_see_pruned`, and
`qsearch_see_fail_open_promotions` are identical.

The fixed-depth release checksum below also shows identical score, best move,
total nodes, qsearch nodes, pruned count, and fail-open count on every paired
run.

## Depth-6 paired performance

Each fixture used five interleaved pairs, alternating:

```text
A B
B A
A B
B A
A B
```

where `A = current-qsearch-pruning` and
`B = current-qsearch-fast-pruning`. `B/A` is elapsed wall time.

| Fixture | Total nodes | Qsearch nodes | SEE pruned | Fail-open | B/A median [p25, p75] |
| --- | ---: | ---: | ---: | ---: | ---: |
| startpos | 68,358 | 52,355 | 4,468 | 0 | 1.008 [0.919, 1.011] |
| open-tactical | 423,347 | 364,749 | 63,037 | 0 | 0.937 [0.931, 0.967] |
| closed-quiet | 174,176 | 142,628 | 26,165 | 0 | 1.030 [1.003, 1.058] |
| exposed-king | 753,764 | 676,925 | 159,668 | 0 | 0.974 [0.910, 0.986] |
| high-branch | 459,806 | 399,881 | 85,928 | 0 | 1.058 [0.963, 1.103] |

All pairs retained the same score and best move. The direct sidecar removes
some SEE overhead on `open-tactical` and is near parity on `exposed-king`, but
the five-fixture sample does not establish a universal 10% wall-time gain;
`startpos`, `closed-quiet`, and `high-branch` remain noisy or slower. This is
therefore a correctness-approved experiment with a failed performance gate,
not a promotion decision. No D1.4.1/D1.4.2 tuning follow-up is authorized;
the expensive part is still position mutation and attack validation rather
than only the attacker scan.
