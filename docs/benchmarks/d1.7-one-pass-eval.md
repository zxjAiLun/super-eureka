## Scope

The candidate preserves the `Current` search tree and replaces only the base
evaluation implementation. A single 64-square loop computes:

```text
white-perspective MG
white-perspective EG
raw non-pawn phase
```

The existing side-to-move perspective conversion, interpolation clamp, and
`finish_evaluation()` path remain unchanged. Exact KQK/KRK mop-up continues to
use its existing board-scan logic. No `Position`, `Undo`, `make_move`, cache,
move generation, search pruning, TT key, or evaluation parameter changed for
D1.7.

## Correctness gate

The one-pass evaluator matches the existing two-pass evaluator on startpos,
queen-win, KQK, KRK, promotion and en-passant positions, plus a deterministic
512-ply legal walk. The evaluation is read-only.

The fixed-depth candidate comparison retains identical:

```text
score
bestmove
complete PV
completed depth
total nodes
qsearch nodes
evaluation-call count
TT probes/stores
```

The new diagnostic counter is base-evaluation-only:

```text
Current:               full_eval_recomputations = eval_calls
                       board_cells_visited = eval_calls * 128
current-one-pass-eval: full_eval_recomputations = eval_calls
                       board_cells_visited = eval_calls * 64
```

`board_cells_visited` does not claim to count the separate exact mop-up scans;
it measures the base evaluation's board traversal only.

Correctness results on the release builds were exact for all reported search
outputs and counters:

```text
depth 6: 10/10 fixtures
depth 7: 5/5 high-cost fixtures
depth 8: startpos
```

The comparisons matched on score, bestmove, complete PV, completed depth,
total nodes, qsearch nodes, evaluation calls, and TT probes/stores. The
one-pass evaluator also matched the existing evaluator on the special-move
and deterministic legal-walk corpus described above.

## Performance gate

The required comparison was:

```text
A = Current
B = current-one-pass-eval
```

It must cover depth 6 on all ten fixtures, depth 7 on the five high-cost
fixtures, depth 8 on startpos, and five interleaved paired rounds. The report
will include score, bestmove, PV, completed depth, nodes, qsearch nodes,
evaluation counters, board-cell counts, elapsed ratio and NPS ratio.

Five interleaved depth-6 rounds produced these B/A elapsed-ratio ranges and
medians:

| Fixture | Median B/A | Minimum | Maximum |
| --- | ---: | ---: | ---: |
| startpos | 0.960 | 0.802 | 1.160 |
| open-tactical | 0.930 | 0.661 | 0.985 |
| closed-quiet | 1.032 | 0.914 | 1.155 |
| exposed-king | 0.974 | 0.846 | 1.043 |
| high-branch | 1.042 | 0.766 | 1.625 |

Three fixtures were faster at the median and two were slower. This is not a
stable general wall-time improvement, so the performance gate is rejected.
The candidate remains available for isolated bench inspection, but no
promotion or Elo conclusion follows from these measurements.
