# S2.2a integrated positional evaluation fixed-time gate

Status: **PASS — candidate eligible for the next independent teacher gate**

This gate compares the approved production `current` profile with the
bench-only `current-eval2` integrated positional-evaluation profile. It does
not change `Current`, and it is not an Elo, game, or SPRT result.

## Scope and provenance

The matrix is pinned to 25 positions, five in each of these groups:

```text
development-coordination
pawn-structure-pawn-push
rook-activity
king-safety-defensive-resource
neutral-control
```

Each position was searched by both profiles at 1,000 ms, 3,000 ms, and
10,000 ms. Every row used a fresh process, cold 16 MB TT, one search thread,
the same release binary, and rotated profile order. The complete matrix is
therefore 25 × 2 × 3 = **150 searches**.

The canonical run was produced after the infrastructure commit:

```text
gate commit:       cbc1077a093ef078c39f427cd72f7a0fdcd34d30
engine SHA-256:    77a10653f0238b5f224c7ffc29b8bd31043f8b0c5dc41a49d5ec60538a31186c
manifest SHA-256:  036701d2a72c2b2efa24acdc6044663477caac8b71f081aca8a2650d61db8319
```

The raw JSON result is a local ignored artifact at
`results/s2.2a/integrated-fixed-time.json`; it is not a committed test
fixture. The runner records the full argv, profile identity, binary hash,
manifest hash, rows, and decision.

## Fixed-time result

The reported values are medians over the 25 positions for each time tier.

| time | Current depth | CurrentEval2 depth | Current NPS | CurrentEval2 NPS | NPS ratio |
|---:|---:|---:|---:|---:|---:|
| 1 s | 5 | 5 | 223,215 | 171,605 | 0.769× |
| 3 s | 6 | 6 | 209,243 | 174,074 | 0.832× |
| 10 s | 6 | 6 | 94,250 | 85,691 | 0.909× |

The paired depth counts by tier were:

```text
1 s:  candidate deeper 1, equal 19, Current deeper 5
3 s:  candidate deeper 0, equal 23, Current deeper 2
10 s: candidate deeper 2, equal 20, Current deeper 3
```

These results show that the integrated candidate remains within the gate's
one-depth tolerance and retains at least 0.65× Current median NPS at every
tier. They do **not** show a stable nominal-depth uplift; the candidate's
median depth was equal to Current at all three tiers.

## Isolation and decision

All 150 searches completed successfully with the expected profile identity,
valid bench result, and empty stderr. The following search-feature counters
were zero for both profiles across the matrix:

```text
aspiration / LMR / null move / futility
SEE and qsearch SEE
check extensions / single-evasion extensions / qsearch check moves
threat ordering / root reordering
```

There were no positions with a stable two-or-more-depth regression across all
three tiers. The fixed-time decision was therefore:

```text
PASS
reasons: []
quality flags: []
```

The gate is a performance and feature-isolation decision only. It does not
authorize a production promotion. `Current` remains unchanged and
`current-eval2` remains candidate-only.
