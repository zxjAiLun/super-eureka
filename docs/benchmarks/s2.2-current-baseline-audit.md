# S2.2 Current baseline audit

Status: **PASS — semantic equivalence and no observed systematic fixed-time regression**

This is a small cross-binary audit required before the S2.2 fixed-time gate. It
does not evaluate `current-eval2`, promote any profile, or provide an Elo
claim.

## Binaries and protocol

```text
A: 65e1f1e  (pre-S2.2 approved Current)
B: bc66ff8  (Current after the E2 fix-forward)
build: release
profile: current
TT: bench default / fresh process per run
fixed-depth: depth 5
fixed-time: movetime 1000 ms
```

The fixed-depth comparison used the same built-in fixture and the same
`bench profile --profile current` command for both binaries. Each row below
matched on score, bestmove, completed depth, full PV, total nodes, qsearch
nodes, evaluation calls, legal move generation, make/unmake, and TT counters.

## Small fixed-time sample

The local sample used three interleaved rounds per fixture:

```text
A B
B A
A B
```

This produced 30 samples per binary. The aggregate medians were:

```text
                    A (65e1f1e)   B (bc66ff8)   B/A
median NPS             192,253.5     197,761.5   1.014
```

The sample is deliberately treated as a non-regression audit only. CPU
frequency, scheduling and the short one-second budget make it unsuitable as a
production throughput claim. No stable depth regression was observed in the
ten fixtures, and B did not show a systematic NPS loss.
