# D1.5 — Current qsearch movegen integration

Status: **COMPLETE — APPROVED**

Parent baseline: `31d833a211db7f7c3c77a7ee131fa94ea79402f6`

## Scope

D1.5 integrates the already reviewed D1.2 specialized qsearch move generator
into `SearchProfile::Current`. Current-based cumulative profiles inherit the
same move-generation source. The behavior is:

- non-check qsearch directly generates captures, en passant, and quiet or
  capturing promotions;
- check qsearch continues to use the complete legal evasion generator;
- a tactical-empty non-check node probes for one legal quiet move before
  stand-pat, preserving stalemate semantics.

No qsearch pruning, SEE, delta pruning, aspiration, LMR, null move, futility,
bitboard, evaluation, TT, or UCI profile change is included. `Current` remains
the only production search profile; D1.3 and D1.4 remain bench-only.

## Cross-binary equality gate

The release binary at parent `31d833a` was compared with the new `Current`
binary using disabled-TT fixed-depth profile searches:

| Matrix | Fixtures | Result |
| --- | --- | --- |
| depth 6 | all 10 standard fixtures | 10/10 exact |
| depth 7 | startpos, open-tactical, closed-quiet, exposed-king, high-branch | 5/5 exact |
| depth 8 | startpos | exact |

Every row preserved completed depth, score, best move, complete PV, total
nodes, qsearch nodes, evaluator calls, TT probes, and TT stores. Representative
depth-6 work counters show the integration effect:

| open-tactical | 44,987,918 → 31,924,882 | 45,514,771 → 31,287,902 |

The full matrix also confirmed equal nodes at depth 7 and depth 8; only the
move-generation counters differ.

## UCI canary

The old and new binaries were started independently with the default `Current`
profile and ran `go movetime 1000` on the same fixed positions:

| Position | Binary | Exit | Bestmove | Depth | Nodes | stderr |
| --- | --- | ---: | --- | ---: | ---: | --- |
| startpos | parent | 0 | b1c3 | 6 | 73,658 | empty |
| startpos | new | 0 | b1c3 | 6 | 73,658 | empty |
| fixed middlegame FEN | parent | 0 | d2d4 | 5 | 34,916 | empty |
| fixed middlegame FEN | new | 0 | d2d4 | 6 | 170,461 | empty |

Both processes completed `uci`/`isready`, returned a legal best move, accepted
`quit`, and were reaped normally. Movetime depth and node differences are
recorded as timing observations, not correctness failures: the two binaries
can reach different completed iterations at a wall-clock deadline.

## Boundary

D1.5 promotes only the D1.2 node-cost optimization into `Current`. D1.3 SEE
pruning remains blocked on external tactical/mate/promotion/endgame
validation, and D1.4 fast SEE is recorded as a correctness-pass/performance-
rejected experiment. No Elo, SPRT, or Current search-tree change is claimed.
