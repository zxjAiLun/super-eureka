# S2.1c — Shared-Core Attribution

Status: **DIAGNOSTIC COMPLETE — `eval-only` retained for the next fixed-time
gate; no production promotion**

S2.1b showed that the full threat-aware package was too expensive and that
`Eval+Order` had a control-position regression. S2.1c separates the two
components shared by those profiles. It does not modify `Current`, run games,
run Stockfish, estimate Elo, or authorize a production change.

## Fixed scope and rotation

The run used the same nine saved S2.1 positions:

```text
king-danger:        3
defensive-resource: 3
control:            3
underlying FENs:    9
profiles:           4
searches:          36
time limit:     3,000 ms
TT:             cold, 16 MB
threads:        1
```

Every row used a fresh process. To avoid assigning one profile the same CPU
temperature/scheduling position for every FEN, the profile order rotated by
position index:

```text
Current → Eval+Order → Eval-Only → Order-Only
Eval+Order → Eval-Only → Order-Only → Current
Eval-Only → Order-Only → Current → Eval+Order
Order-Only → Current → Eval+Order → Eval-Only
```

The canonical executable was built from `69bb7e6`. The complete raw artifact
is [`shared-core-3s.json`](../../results/s2.1c/shared-core-3s.json); it records
the executable hash, manifest hash, every row, and each rotated execution
order.

The four bench-only profiles were:

```text
current-threat-aware-eval-order  king-danger eval + threat/root ordering
current-threat-aware-eval-only   king-danger eval only
current-threat-aware-order-only  threat/root ordering only, Current eval
current                           approved production reference
```

All four retain Current's PVS and specialized qsearch move generation. None
enables forcing extensions or quiet qsearch checks; those components were
already rejected by S2.1b.

## Quality attribution from existing teacher data

The following comparisons reuse rows already present in
`results/s2.1/teacher-rescore-500k.json`; S2.1c did not invoke Stockfish.

### Control regression is the eval/order interaction

On `s21-control-237-32`:

```text
Current:    g8f8 — losing_mate_delayed, non-harmful
Eval+Order: g8h8 — losing_mate_accelerated, harmful
Eval-Only:  g8f8 — same safe choice as Current
Order-Only: g8f8 — same safe choice as Current
```

Neither isolated component reproduces `g8h8`; the regression requires their
combination or an interaction between them.

### Evaluation retains the useful selected-position signals

On `s21-attack-616-31`:

```text
Current / Order-Only: f5g4 — losing_mate_accelerated
Eval+Order / Eval-Only: c6e5 — 108 cp loss, avoids that mate swing
```

On `s21-defense-143-7`:

```text
Current / Order-Only: h5g6 — 95 cp loss
Eval+Order / Eval-Only: a7a6 — 0 cp loss
```

On `s21-defense-293-39`, the known teacher comparison is close (`c3e4` at
18 cp versus `h2h1` at 20 cp), so it is not counted as a decisive gain.
These are selected-position teacher observations, not a general strength
claim.
