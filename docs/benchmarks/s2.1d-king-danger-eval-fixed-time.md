# S2.1d — King-Danger Evaluation Fixed-Time Gate

Status: **FAIL — EvalOnly remains bench-only; `Current` unchanged**

S2.1c isolated `current-threat-aware-eval-only` as the only remaining
candidate worth a fixed-time gate. S2.1d compares only that profile with the
approved `Current` profile. It does not modify search behavior, run
Stockfish, run games, estimate Elo, or authorize a production change.

## Scope and integrity

The canonical run used the same nine saved S2.1 positions at three time
limits:

```text
positions: 9
profiles:  current, current-threat-aware-eval-only
time:      1,000 / 3,000 / 10,000 ms
searches:  54
TT:        cold, 16 MB
threads:   1
process:   fresh engine process for every row
```

For each position/time pair the two profile order was reversed when
`(time_index + position_index)` was odd. The artifact records the actual
order, executable SHA-256, manifest SHA-256, and engine-source Git SHA:

[`eval-only-fixed-time.json`](../../results/s2.1d/eval-only-fixed-time.json)

The engine binary was built from `7f99ca6`.

## Fixed-time depth result

The per-time aggregate was:

| time | Current median depth | EvalOnly median depth | EvalOnly deeper | equal | Current deeper |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 s | 5 | 5 | 0 | 6 | 3 |
| 3 s | 6 | 6 | 1 | 6 | 2 |
| 10 s | 7 | 7 | 1 | 7 | 1 |

Across all 27 position/time pairs:

```text
EvalOnly deeper:  2
Equal:           19

```

The median-depth criterion passed at all three time limits. There was no
position that stayed behind at every time limit, and no position with a
stable two-or-more-depth regression. However, the required aggregate balance
criterion failed: EvalOnly's deeper-pair count was smaller than Current's.

## Decision

```text
S2.1d fixed-time gate: FAIL
EvalOnly:             BENCH-ONLY / NOT PROMOTED
Stockfish rescore:    NOT RUN
Games / Elo / SPRT:   NOT AUTHORIZED
Current:              UNCHANGED
```

The failure is a performance/decision gate failure, not a protocol or
feature-contamination failure. The gate is closed without retuning
king-danger weights and without adding ordering, extensions, quiet checks,
LMR, null move, futility, SEE, mobility, pawn structure, or other E2 work.
