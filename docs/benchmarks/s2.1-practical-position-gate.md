# S2.1 — Practical Position Gate

Status: **DIAGNOSTIC MIXED — SEARCH COST NEGATIVE, MOVE QUALITY PRELIMINARY POSITIVE / UNVERIFIED**

This gate compares the approved `Current` profile with the isolated
`current-threat-aware` candidate on saved positions from the stopped D1.14
pilot. It does not modify `Current`, start a match, or convert local position
results into Elo. The fixed-time depth result below is a throughput result,
not a complete move-quality verdict: this candidate uses selective extensions
and extra qsearch checks, so nominal completed depth is not directly
comparable to the amount of tactical work searched at that depth.

## Scope and provenance

The position manifest is
`tests/data/s2.1-practical-positions.json` and contains nine positions:

```text

defensive-resource   3

```

The labels are analyst labels for a practical diagnostic. They are not mate

The saved Stockfish move in the manifest is retained only as a diagnostic

## Execution contract

Each row used a fresh release process and a cold 16 MB TT:

```text
profiles:       current vs current-threat-aware
Hash:           16 MB
threads:        1
TT mode:        cold, one process per profile/position/time
time limits:    1,000 ms / 3,000 ms / 10,000 ms
positions:      9
searches:       3 × 9 × 2 = 54
```

The runner first performed a UCI identity probe for each executable, then used
the profile bench entry with the exact FEN. It recorded score-by-depth,
completed depth, bestmove, PV, nodes, elapsed time, NPS, and:

```text
check_extensions
single_evasion_extensions
qsearch_check_moves
```

The release binary was built from `b6e784d0c4332b3e63e0596bc29cbe41d6e0b572`.
The two executable copies had the same SHA-256, as expected; their only
intended difference was the selected profile:

```text

```

Before building the candidate, the TT layout was measured at both the

## Depth result

The final artifact completed all 54 searches without a process, protocol, or
stderr failure. Candidate depth uplift means the candidate completed a higher
depth than `Current` for the same position and time limit.

| time | Current median depth | candidate median depth | candidate uplift | Current uplift | equal depth |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 1 s  | 5 | 3 | 0/9 | 8/9 | 1/9 |
| 3 s  | 5 | 4 | 0/9 | 9/9 | 0/9 |
| 10 s | 6 | 4 | 0/9 | 9/9 | 0/9 |

This is a negative fixed-time **search-cost and nominal-depth** signal for the
candidate on this practical slice. The candidate does execute its intended
extra work, but the bounded extensions and qsearch checks do not compensate
for their cost here. Because the candidate's selective work changes the
meaning of nominal depth, this result alone is not a move-quality verdict and
is not a proof that the candidate is weaker in every position.

No short match was started. The teacher slice authorizes a narrowly scoped
S2.1 redesign investigation, not a match or production promotion. The first
candidate redesign should reduce the cost of quiet-check qsearch (starting
with qply 0 only or a conservative danger threshold), then remeasure the
same fixed-time gate. Do not stack LMR, null move, futility, SEE pruning, or
other search changes into that redesign.
