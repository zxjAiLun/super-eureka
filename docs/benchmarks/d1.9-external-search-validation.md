# D1.9 — External search-safety validation harness

Status: **INFRASTRUCTURE COMPLETE — VALIDATION-ONLY, NO PROFILE PROMOTION**

## Scope

D1.9 adds a versioned, external-to-the-search-code validation harness. The
manifest is a small project-curated CC0 corpus, not an Elo suite and not a
claim of broad tactical coverage. It is intentionally kept in the repository
so additions and removals are reviewable:

```text
tests/data/search_validation.epd
tests/search_validation.rs
```

Each entry records:

```text
id
category
full FEN
allowed best moves
expected score class
minimum depth
source
license
```

The initial corpus covers tactical captures, checking captures, mate
sequences, quiet and underpromotions, promotion races, en passant,
sacrifice/recapture context, stalemate, and KQK/KRK.

The test starts real UCI child processes and runs both:

```text
current
current-qsearch-pruning
```

The latter is exposed through the startup profile parser only for this
validation use. It remains a candidate profile and is not part of `Current`.

## Safety gate

For every case and profile the harness checks:

- UCI handshake identity;
- process exit and `bestmove` completion;
- legal bestmove, including terminal `0000` semantics;
- allowed-bestmove membership when the case specifies one;
- expected mate/winning/non-losing/terminal score class.

It then rejects a candidate if its coarse score class is below the Current
baseline. PV equality and exact centipawn equality are deliberately not
required: a safe pruning candidate may choose a different equivalent move or
change a non-terminal score without losing the tactical result.

The gate is run with:

```text
cargo test --test search_validation
```

This is a validation gate only. It does not authorize `Current` changes,
SEE-pruning promotion, delta pruning, Elo/SPRT, or any new search feature.
The corpus must grow through separately reviewed, pinned cases before it can
serve as evidence for production promotion.

## Boundary

```text
Current: unchanged
current-qsearch-pruning: validation-only candidate
D1.3 production promotion: still blocked by broader validation
delta pruning: deferred
Elo/SPRT: deferred
```
