# S14 三局送马：时间／深度阶梯与强制后续节点诊断

日期：2026-09-19。前置：[云端案例核查](2026-09-19-s14-cloud-knight-loss-diagnostics.md)。

## 结论

**同一生产二进制和模型、保留完整对局历史，三个原局面都复现了历史坏招；加深后都改为其它走法，但纠正阈值不同。第127局已得到可重复的安静将死边界案例。**

这支持“有限搜索深度是这些错误的重要条件”，不等于已证明“只改时间管理就解决问题”，更不等于“延长时间会改变 S15–S17 的相对排名”。未修改搜索代码、未训练、未追加比赛。

## 优先案例：第127局安静将死边界

原PV：

```text
25.Nxe5 Bxe5 26.Qxe5 Qf3+ 27.Kg1
```

随后黑方 `...Qg2#` 是合法、不吃子的将死。`...Qf3+` 后白方仅有 `Kg1` 与 `Kh2`，**两者均被 `...Qg2#` 将死**。

### 已直接复现的断层

保留完整历史，推进到 `...Qf3+` 后：

| 请求 | 结果（白方视角） | PV |
|---|---|---|
| depth 1 | **+2.00** | Kg1 |
| depth 2 | **mate −1** | Kg1 Qg2# |

另起新进程重复，两档评分与PV一致。推进到 `Kg1` 后以黑方为根，**depth 1 就得到 `Qg2# / mate +1`**。终局节点输出 `bestmove 0000`。

向上游追踪也一致：

- `Nxe5 Bxe5` 后，d1仍计划 `Qxe5`，报白方 +1.82；d4改 `Kh2`，报−0.60。
- `Nxe5 Bxe5 Qxe5` 后，d2仍报白方 +2.00；d4识别白方被将死（黑方 mate 2）。
- 根局面d5仍选Nxe5，d6才放弃，d7转向Qe3。

### 静态评分与源码吻合

生产 `bench nnue-v2q-probe` 的 `prediction_cp` **仅为网络残差**，不能直接作为完整静态评估。按生产公式复算：

```text
residual_i32 = round_half_away(raw_output * 1000 / 4096)
full_static  = residual_i32 + material_cp_stm
P=100, N=320, B=330, R=500, Q=900, K=0
```

在 `...Qf3+ Kg1` 后的叶子，换成白方视角：

```text
材料 +210cp + 网络残差 −10cp = 完整静态评估 +200cp
```

**恰好等于父节点depth1的乐观+200cp**。生产源码非被将军qsearch不生成quiet check，而此时黑方不在将军中、Qg2不吃子不升变，因此没有被该战术走法集合覆盖。向主搜索多给一层，就读出了将死。

现在能说：**可重复的有限深度战术盲区已经定位到这条强制线，quiet-check范围与结果吻合。**

仍不能说：已证明对quiet checks做某个补丁必然最优、所有送子均同因、或整个评估网络架构错误。本轮没有修改qsearch，也没有做关闭剪枝/TT等消融；不把完整PV看成整个搜索树的trace。

## 其它两局：既有视野问题，也有乐观评估

### 第175局（Qc1 / ...Qxf3）

- `Qc1` 后，以黑方为根d1–4仍选其它走法、认为白方略好；d6找到 **Qxf3**，评分转为白方−1.44。
- 直接推进到`Qxf3`后，d1报白方+2.68，d6才降为−1.44。
- 该节点完整静态分解：**材料−390cp，网络残差+525cp，合计+135cp**。
- 因此不能仅说“根部没有时间看到被吃”：已经失马的节点也有乐观补偿估计，搜索加深才进一步纠正。g2兵被钉、不能吃回后的规则事实未变。

### 第187局（Nd5 / ...exd5）

- `Nd5`后黑方d4/d6选Nf6，仍给白方+0.96/+1.05；**d7找到exd5**，改为白方−0.37，d8为−0.43。
- 对`Nd5 exd5`后的白方节点，d7选exd5，白方−0.43。
- 吃回兵后完整静态评估：**材料−220cp，网络残差+190cp，合计−30cp**；已有SF100k在这个节点约−2.66兵。
- 根d8不再走Nd5，但本轮未额外重分析Qd3的最优性，不能把“避开这一坏招”夸大为“棋力已修好”。

这些静态分解不是修复目标：不要直接把“少子补偿估计偏乐观”变成新的硬惩罚，或因为静态网络没报将死就要求它替代合法走法搜索。
